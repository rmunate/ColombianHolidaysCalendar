# Reportar un error

Abre un [issue en GitHub](https://github.com/rmunate/ColombianHolidaysCalendar/issues/new) con las versiones de PHP, Laravel y el paquete, la consulta mínima y los resultados esperado y observado.

Si el error está en el calendario, incluye la fecha observada y una fuente que indique la norma aplicable. No incluyas credenciales ni datos privados de tu aplicación.
